# morningmealChuseok

> 은은한 보름달 속에 사진과 따뜻한 소원을 담아 움직이는 엽서와 고화질 이미지를 제작하는 웹 애플리케이션입니다. 별도의 서버 없이 브라우저 환경에서 정적으로 동작합니다.

## 🛠 기술 스택

- **Frontend**: HTML5 Canvas, Vanilla JavaScript (ES6+)
- **Styling**: Tailwind CSS (CDN)
- **GIF Encoding**: [gifshot](https://github.com/yahoo/gifshot) (브라우저 메모리 기반 클라이언트 인코딩)
- **Icons & Fonts**: Lucide Icons, Google Fonts (고운 바탕, Pretendard)
- **Hosting**: GitHub Pages 호환 (정적 웹)
